# ROAd – Robotaxi Optimized Allocation

Politecnico di Milano — **Software Engineering for Automation** course project.

ROAd (*Robotaxi Optimized Allocation*) is a system for managing an autonomous ride-sharing service based on a fleet of robotaxis.

## Deliverables

The project is organized into three main deliverables:

- **[Requirements Analysis and Specification Document (RASD)](RASD/ROAd_RASD.pdf)**  
  Requirements analysis, system goals, domain model, use cases and system requirements.

- **[Design Document (DD)](DD/ROAd_DD.pdf)**  
  System architecture, component design, interfaces, runtime behavior and design decisions.

- **[Implementation](Implementation/)**  
  Complete implementation of the ROAd system and demonstration scenarios.  
  Open the **[Implementation README](Implementation/README.md)** for installation instructions, execution commands and demo procedures.
